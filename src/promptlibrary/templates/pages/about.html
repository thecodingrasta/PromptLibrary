What it does

PromptLibrary stores prompts, versions, metadata and ordered workflows in a local SQLite library. It provides both a browser interface and an MCP interface over the same services, so changes remain consistent whichever interface you use.

Workflow runs record the inputs and outputs you provide. PromptLibrary does not call an AI provider or execute commands on your behalf.

How it stays yours

The application is self-hosted and designed for one operator. Portable exports omit credentials and machine-local settings. Keep the SQLite data directory on a local filesystem and maintain backups before migrations or restores.
