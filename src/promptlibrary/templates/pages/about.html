PromptLibrary

Version {{ version }}

A self-hosted library for prompts and ordered workflows, with version history, portable snapshots and an MCP interface for agents.

What runs here

Python, FastAPI and SQLite provide the application and storage. Pages are rendered on the server, with local JavaScript for navigation, confirmations and clipboard actions. There are no required third-party frontend requests.

Workflow runs record inputs and outputs. They do not call an AI provider. Use your chosen tool or an MCP-connected agent as the runner.

Access and privacy

PromptLibrary is a single-library, single-operator application. Anyone with access to its web account or local MCP process can read and change the library, including notes and saved outputs. It does not provide per-user permissions or tenant isolation.
