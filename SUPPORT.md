# Support

Start with the [user guide](src/promptlibrary/content/user-guide.md),
[configuration](docs/configuration.md) and [troubleshooting](docs/troubleshooting.md).

For a reproducible bug, open an issue with the application version, operating
system, Python version, installation method, steps and expected result. Include
an error's request ID where available. Use a temporary library and invented prompt
content when sharing a reproduction.

Do not attach `.env`, `sync.key`, a real database or an unredacted backup. Security
reports belong in the private route described in [SECURITY.md](SECURITY.md).
Community support is best-effort; no service-level agreement is implied.
